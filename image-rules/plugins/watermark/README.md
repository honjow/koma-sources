# 漫画水印清理

插件 ID 为 `comic-watermarks`，沿 [图片插件作者指南](../README.md) 构建和分发。宿主按图片像素判断适用性，转载同一版式的书源也能命中。

## 已收录样式

识别 800 像素宽页面左右下角的已验证版式。右侧支持拷贝漫画、DM5 横排、竖排、斜排和集云数据的实测组合。左侧支持 DM5 斜排、竖排和集云数据，含白边叠加，以及黑边的斜排、竖排 DM5。两侧独立匹配，同页可以同时处理。尺寸、位置、颜色或背景条件超出已验证样式时保留原图。

留白检测同时要求水印形状、完整区域亮度和低色差，以及一圈平坦背景匹配。靠近分格线时，只允许缩减模板上方多余的留白，并仍保留一行背景用于核对。画面上的 DM5 与拷贝漫画先用浅底、深底签名核对水印，再依据邻近的颜色或贯穿水印的同方向线条恢复像素。透过水印的像素可反算，并和周围画面交叉核对。高置信度集云数据叠在画面上、形状不确定或线条无法连续恢复时保留原图。

黑白分格线在框边走向和两侧颜色均能核实时，可从未遮挡的直线恢复框线，并独立清理框外留白。复杂网点、曲线或大片叠加水印依旧保留正文。

成功时仅替换匹配区域，保留页面尺寸、其余 RGBA 像素与原始下载。插件输出沿宿主默认的无损 PNG 路径。

## 样式来源和更新

签名从瓜子漫画所载《归还者的魔法要特别》原图中的留白区域取得。仓库只收录这些区域的灰度签名。

- 白边拷贝、三种 DM5 组合分别以第 124 话第 8、7、11、4 页为代表。
- 白边集云数据及其与斜排、横排 DM5 的组合分别以第 124 话第 20、12、24 页为代表。竖排叠加样式来自第 123 话第 12、60 页。
- 黑边拷贝和 DM5 横排、竖排、斜排组合分别以第 125 话第 6、4、14、22 页为代表。
- 左侧白边版式来自第 124 话第 4、8、14、48、49 页等，黑边来自第 124 话第 87 页及第 125 话第 6、13、24 页等。

新增样式时，先确认原始像素的页面宽度、水印位置和留白。选择同一版式的数张对齐样本，裁出的矩形应包含标志、压缩边缘和一圈干净背景。用 `build_pattern.py` 生成模板，参数 `--box` 按侧边距、底边距、矩形宽、矩形高填写原图像素，默认右侧，左侧另加 `--side left`。黑边样本另加 `--background black`。将新签名加入对应一侧的签名列表，有共同区域的组合排在较小样式之前。验证带标记、无标记和标记压住画面的原图后，再递增插件清单版本并更新支持清单。
