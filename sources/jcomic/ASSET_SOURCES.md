# JComic 图标

[官网归档首页](https://web.archive.org/web/20221103114642id_/https://jcomic.net/) 的导航品牌链接包含 `glyphicon glyphicon-fire`，后跟站名 JComic。现网首页保留这一组合。该站点的历史 favicon 存档为空响应。

[官网 CSS](https://jcomic.net/view/css/bootstrap.min.css?aa) 将图形映射到 U+E104，导航品牌前景色为 #9d9d9d。[官网字体原件](https://jcomic.net/view/fonts/glyphicons-halflings-regular.woff) 与 [官网字体历史存档](https://web.archive.org/web/20221107060533id_/https://jcomic.net/view/fonts/glyphicons-halflings-regular.woff2) 可核对。素材为官网实际使用的 [Glyphicons Halflings](https://getbootstrap.com/docs/3.4/components/#glyphicons) 字形。

沿用官网导航实际使用的火焰字形及 CSS 原色。裁掉栅格稿多余的透明留白，使字形占正方形长边的约九成。
