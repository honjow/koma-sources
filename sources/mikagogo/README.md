# 米卡插画

## 0.1.1 簡介與多語言顯示

米卡插畫收錄插畫、畫師圖集、畫冊、壁紙與 COSPLAY 相冊。此入口閱讀公開圖集，會員或積分下載的高清檔案由原站提供。

零參 `source_info` 固定使用以上基準簡介；`metadata.localization` 僅新增 `source.description` 的繁中、簡中與英文文案，供支援的宿主顯示。

参考 [Keiyoushi Mikagogo](https://github.com/keiyoushi/extensions-source/tree/f1d882a93ef34a33dc4f4467753ad5f99eab43f4/src/zh/mikagogo)。保留热门、最新、分类、关键词和站内作品链接。关键词搜索可按分类筛选，沿用官网搜索结果的顺序。每个公开相册作为一章，按站点分页衔接图组。

作品评论读取官网现有评论列表，使用 WordPress 原评论编号。会员或者积分下载的高清文件由原站提供。
