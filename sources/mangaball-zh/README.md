# MangaBall Chinese 0.1.3

Independent source `com.mangaball.zh.koma`, API 0.2, language zh. Chinese selects chapter language; it does not guarantee Chinese titles or a particular script. Existing `mb:`/`mbc:`/page identities, provider chapter order, actual chapter/volume numbers and exact page ownership remain. The existing 512px MangaBall identity icon is unchanged; official site branding uses MangaBall; see NOTICE for attribution.

Public list/search/detail/Chinese chapters/pages use canonical `mangaball.com`, the existing exact cover/page hosts and existing bounded JSON and pagination validation. No cookies, account credentials, mirrors, scripts, statistics requests, inferred chapter numbers or URL rewrites are introduced. Malformed, duplicate, incomplete and forbidden entities remain errors. Paid/locked chapter and page guards remain independent of list settings.

`nsfw_pref` (Hide NSFW content) defaults **true**, preserving Koma's explicitly adopted non-adult default and `adult_mode=no_18`. Explicit false uses the reference `adult_mode=all`; unknown/missing adult flags still fail validation. This controls listing/search requests, without changing existing per-book permissions.

`scanlator_blacklist_pref` (Scanlator blacklist) defaults to an empty array and is available only when the host declares both `source_setting_observations_v1` and `source_chapter_exclusions_v1`. Successful Chinese chapter lists return their actual nonblank raw group names in `data.settingObservations.known_scanlators_pref`; `get_settings` consumes the host's source-specific union from `args.settingObservations`. Options preserve raw names and sort by Unicode-lowercased UTF-16 order. An initially empty union yields an empty multi-select, matching the fixed reference; no fabricated choices are inserted. The host owns observation persistence, separately from selected settings.

Filtering compares each group and selected value after trim and complete Unicode lowercase, with exact equality. Rust `alloc::str::to_lowercase` and `dlmalloc` support the existing no_std WASM without approximating contextual Unicode rules. Original ownership, permissions, number/title validation run before filtering; filtering all valid Chinese chapters succeeds with an empty list, while an originally absent Chinese catalogue retains its existing error. Observations are collected before blacklist filtering, so hiding a group does not erase its selectable name. Older hosts lacking either capability ignore saved blacklist values; observation-capable hosts can still learn real names independently.

Complete filtered catalogues also return `data.excludedChapterIds`, containing only the actual validated full chapter IDs removed by the current selection. The host can omit these IDs from retained detail UI without deleting Library chapters, downloads or reading state; other missing chapters retain the existing protection. An exact `args.chapterId` resume request validates the full response and returns only that legitimate original chapter, independently of directory blacklisting, with no fabricated replacement or ID fallback. Missing exact chapters remain not found.

Settings follow Keiyoushi `949dea252eb8e867b7b40834a26e13088764ff55` MangaBall/ScanlatorBlacklist; the default-true adult setting is the explicit Koma adaptation. Build with `bash build.sh --source mangaball-zh`; the standard packager retains localized names from metadata.json. Historical cover access failures are not declared resolved by these settings. A successful build or controlled response replay does not establish current content or native image availability.
