# 数码宝贝官网

## 站点简介

数码宝贝官网的《DIGIMON DREAMERS》中文连载。薮野展也画少年鼓堂律被召进数码世界，帮助搭档脉冲兽打破无法进化的诅咒。

参考 [Keiyoushi Digimon Web](https://github.com/keiyoushi/extensions-source/tree/f1d882a93ef34a33dc4f4467753ad5f99eab43f4/src/all/digimonweb) 的中文来源。作品目录取自官网的中文 DIGIMON DREAMERS 页面，仅提供该语言的作品。关键词搜索仍匹配官网作品标题，亦可使用作品或章节网页地址。官方没有按更新日期排序的中文栏目。

章节身份使用网站路径。目录按官网章节号续读，正文按图名中的真实页码排序，适配原页图组的倒序排布。
