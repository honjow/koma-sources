# 18漫画

## 站点简介

18漫画是繁体中文成人韩漫站，能找到《秘密教学》《美丽新世界》等分季连载。正篇之外，也会列出外传和作者后记。

独立源 `org.18mh.koma`，首次参考 Keiyoushi 8947c372 的 18Manhua / GoDa。保存 Mihon 来源 ID `5706270060628375954`。GoDa 和 18 漫画各自的源身份及正文请求独立。

| 功能 | 上游行为与本源 |
| --- | --- |
| 热门与更新 | `/hots/page/{n}` 与 `/newss/page/{n}`，读取卡片，按可点击的站点下一页判断。 |
| 搜索、分类 | 文字进入 `/s/{query}?page=`，空关键词使用目录筛选。类型与真实分类页标题栏同步。 |
| 作品与目录 | `/manga/{slug}` 保留站点详情及 `data-mid`。从原站 `/manga/get` 取得独立目录，章路径和数值 ID 均按原链接；由旧到新反转。 |
| 阅读 | `/chapter/getcontent` HTML 读取 `#chapcontent` 内原有页序和实际地址。 |

当前本机的入口请求被站点拒绝。官网公开存档 HTML 可用于核对详情结构，实机和正文联网仍待验收。

0.1.2 为原站 HTTPS 地址声明网页验证。收到 Cloudflare 明确的挑战信号时，沿用 Koma 的网页验证界面；普通 403 仍按站点拒绝处理。热门、搜索、作品和章节沿原 Goda 请求及解析逻辑。

0.1.3 使用已验证的原站页面接续浏览，出现漫画列表、章节目录或漫画图片后自动关闭验证页。打开筛选时才加载原站分类。年龄确认留在网站原有流程中。最低 App 版本为 Koma 1.6.1。
