# ComicFury official identity resource

Version 0.1.2 uses the complete original 192×192 PNG already retained as
identity.original.png. The official https://comicfury.com/ site.webmanifest
explicitly declares /android-chrome-192x192.png; the official Apple icon uses
the same mascot. A current ordinary homepage read still declares the manifest
and Apple icon. The newly declared /images/favicon.png is the same identity
at only 64×64 and was not substituted for the larger retained original.

icon.png is copied without cropping, tracing, recoloring or added backing,
shadow or mask. The green background belongs to the official original.
This replaces the displayed derived polygon asset from version 0.1.1.
identity.derived.svg remains historical source material, not the active icon.
App slot size, rounded presentation, ordering and provider behavior are unchanged.
Brand/icon rights remain with ComicFury; no affiliation is asserted.
