# MangaDex 0.1.20

Independent source `org.mangadex.koma`, API 0.2, language en. Existing `mdx:` manga IDs, `ch:` chapter identities, original official icon and [asset attribution](ASSET_SOURCES.md) remain. Ordinary public search/list/detail/Home, exact chapter restoration and existing filters remain; no external provider body is followed.

Settings retain `language` (default en) and `dataSaver` (default false). Old Hosts retain `defaultContentRating` (default suggestive). Explicit request filters retain their existing precedence. `thumbnailQuality_en` follows fixed Keiyoushi 949dea252eb8e867b7b40834a26e13088764ff55: original, medium `.512.jpg`, low `.256.jpg`. Nonempty Host value `original` encodes the upstream empty suffix. Missing/unknown quality leaves original URLs unchanged. The selected published suffix is consumed by search, list, detail and all Home sections; existing missing-cover handling is unchanged.

Chapter IDs, title fallbacks and original directory order remain. Null/missing/empty/nonstring chapter numbers remain unknown; actual zero and fractional numbers retain their values. No dates are inferred. The existing mdxc1 pagination state preserves full external-only terminal detection; empty catalogues, hosted/external mixed results, pagination errors and unsupported external-only results remain distinct.

Existing data-saver pages use the actual selected API filename array and corresponding data/data-saver path, retaining page index IDs. No account/token/Cookie flow, statistics side effect, new source/host grant or App style is introduced. Standard build: `bash build.sh --source mangadex`. Runtime/crate/package versions align at 0.1.20.

`altTitlesInDesc_en` defaults false and is consumed only by manga detail descriptions. Explicit true appends the fixed reference `Alternative titles:` block: extension-language or original-language romanized maps, exactly one nonempty value per map, provider order, no sorting/deduplication. The shared SDK plain-text helper decodes JSON Unicode and HTML entities once while preserving literal markup; the original base description is retained. Missing/false leaves the prior description bytes, title fallback and all other fields unchanged. Title priority and final-chapter text have independent settings below.

`usePort443_en`（Use HTTPS port 443 only）默认false。沿固定Keiyoushi949dea的实际消费者，只在显式开启时给at-home服务器查询追加 `?forcePort443=true`；默认请求原样。图片URL、页ID/序和校验仍取真实响应，不向URL硬写端口，不改其它API、封面、认证、网络、超时或重试。

`tryUsingFirstVolumeCover_en` defaults false. Explicit true follows the fixed reference bulk `/cover` query ordered by volume, selecting the first cover related to each returned manga with its original-language locale. Search/list/detail and all Home sections consume it before applying the existing cover-quality suffix. Missing locale, no matching cover, unsafe filename or optional HTTP/parse failure keeps the original cover. Default requests and cover URLs remain unchanged; no chapter/page/identity or Library data is rewritten. Existing library covers require their ordinary explicit refresh. The shared provider implementation is `sources/mangadex/first_volume_cover.rs`.

`originalLanguage_en` is the fixed original-publication-language multiselect (Japanese/Chinese/Korean), empty by default. It filters public list/search and Home sections requests only; Chinese includes both `zh` and `zh-hk`. It does not select translated chapter language, rewrite IDs or Library titles, or filter exact detail/chapter/image restoration. Missing/empty selection preserves previous requests and output.

On Hosts declaring `source_settings_context_v1`, get_settings with present `args.settingValues` replaces the old three-value `defaultContentRating` selector with the fixed `contentRating_en` multiselect (safe/suggestive/erotica/pornographic). Missing new array inherits old safe→[safe], erotica→[safe,suggestive,erotica], and suggestive/missing/unknown→[safe,suggestive]. The old Erotica choice never implied pornographic. Schema reads are pure; only ordinary explicit Save persists the new array. Empty or failed context is distinguished: read-empty `{}` gets reference defaults, absent context keeps old schema. Missing feature keeps old schema and legacy consumption even if a new array was stored. The new array wins on supported Hosts, with existing explicit single-class filters still taking precedence; Home uses the saved set. Details, chapter/page identity and Library titles are unchanged.

## 完结卷章说明

`finalChapterInDesc_en`（Final chapter in description）默认关闭，保当前Koma无配置的简介；固定参考默认开启，这里保留既定缺省输出。显式开启仅在详情末尾按固定MangaDexHelper拼接非空 `lastVolume`/`lastChapter` 为 `Final chapter:\nVol.x Ch.y`，在已有简介/别名后隔一空行，并按原实体表解码一次。沿上游原字符串，不猜最大章、不要求数字、不剥正文标签。缺少两值不造段落，非法字段或容量不足明确失败。列表、HTTP、标题、ID、目录/页顺序和已存Library不主动变化。

## 标题优先顺序

`preferExtensionLangTitle_en`（Use alternative titles）默认true，保当前Koma原标题优先链与原JSON输出，固定参考也是true但既有链的细节不据此重写。显式关闭沿固定MangaDexHelper：扩展语种primary值仍优先，缺失才用primary首value，再回扩展语种单值alt、英文单值alt，并实体解码一次。列表、搜索、详情及已有Home共用；不排序或去重标题，不主动重写Library名称、ID、目录及页面。显式关闭时按参考区分空字符串与缺失值，不因字符串为空继续回退；默认和开启仍保原空标题处理，容量不足明确失败。

`blockedGroups_en` and `blockedUploader_en` are comma-separated UUID text settings exposed only when the host declares both `source_setting_uuid_list_v1` and `source_chapter_exclusions_v1`. Both default empty; empty or older hosts preserve existing requests and results. The host validates the fields before saving; the source also rejects invalid values rather than adding unchecked query parameters. The normal chapter feed applies both exclusions and reports the complete excluded chapter IDs across the successful paginated traversal, preserving stored chapters and progress. Exact chapter recovery and page ownership checks bypass these filters. When exclusions are active, default English Latest and its Home section use the chapter endpoint and fetch its distinct manga IDs. Explicit ordering preserves the original manga order and filters it by chapter availability under the same exclusions; ordinary manga search and other listings retain their existing requests.

When English Latest returns more than 20 manga under exclusions, the existing first-volume cover preference applies the same ordered locale match to each bounded batch; failures keep each original cover. The preference remains disabled by default.

Search decodes the JSON query before URL encoding, preserving literal quotes, backslashes and Unicode. Search applies the existing status, demographic and order filters; missing or default values retain the original request and relevance order. Empty searches and pagination retain their existing behavior.
