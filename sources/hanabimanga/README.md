# 花火漫画

目录、排行、筛选、搜索、作品及章节沿用上游公开接口。正文采用官网浏览器的阅读接口，保留登录、额度及权限检查，并校对返回的作品和章节 ID。官网随页表返回票据时，宿主解码后调用随包处理器，用站点返回的列数和行数拼回图块。
