# 東立

使用東立电子书站点的公开目录、详情和其授权的章节/页图接口。当前没有可编辑的源设置，也不提供付费内容解锁；作品可能受站点地区限制。

- 0.1.2 修复匿名认证返回 HTTP 400 时提前退出、未进入已有备用认证分支的问题。403、限流、服务错误或网络失败仍保留，不切换认证；无设置明确返回“不支持”。
- 0.1.3 只将站点 HTTP 400、`Succeeded=false`、`Errors.Code=3166` 的明确业务错误保留为地区限制；不根据任意错误文字推测，也不更改网络或账户绕过限制。准确的本地化提示需 App 支持该原因。

2026-10-24 已在 237 普通远端安装/更新后确认：0.1.1 的《膽大黨》章节认证失败，在 0.1.2 恢复为 4 条可见章节；首话取页仍返回 HTTP 400。桌面同接口明确返回地区限制 3166。0.1.3 与当前 App 的原生提示待实机组合验证，不将目录、编译或安装成功视为可阅读。账户权限、付费章节和站点可用性仍各有边界。
