# 漫蛙

独立包 `com.manwa.koma`，对应 [Keiyoushi 固定模块](https://github.com/keiyoushi/extensions-source/tree/8947c372cd87f546a0b80cb0e4b0a5a8add5ef88/src/zh/manwa) v3 和 Mihon ID `1795888684783606321`。沿用 Mihon 的 `/book/{数字 ID}`。官网三份存档目录均使用 `/chapter/{数字 ID}`，按真实路径声明章节身份。跨端完整页序尚待核对。站点身份及图标原件见 `ASSET_SOURCES.md`。

| 上游行为 | Koma 入口与实现 |
| --- | --- |
| 排行和更新 | `get_manga_list` 的热门只取 `/rank` 的 `#rankList_2`，无分页。更新从 `args.page.cursor` 计算 `/getUpdate?page=(页号-1)*15&date=`，按 `total` 决定下一页；另从有图源设置的 `/update` 读取图片基址。无独立首页。 |
| 分类与搜索 | `search` 的空词或含半角连字符走 `/booklist`；其余词走 `/search?keyword=`。分类保留状态、类型、地区、排序默认值及复数标签，选择“全部”时去掉 `tag` 参数。标签由 `get_filters` 在宿主实际打开筛选时从分类页读取。首屏省略页号，末项为“下一页”才继续。 |
| 详情与章节 | 保留原站标题、作者兼画师、封面、简介、更新状态和标签。详情和目录均调用 `/book/{id}`，目录按上游倒序并使用 SDK 显式章序。整书更新日期仅赋给最新章。没有原文 Markdown 渲染时使用可读纯文本。 |
| 正文 | `get_pages` 先发送最佳努力的 `pv.gif` 请求，再取章节文档中 `#cp_img > div.img-content > img[data-r-src]`。保留原图顺序。`get_image_request` 识别 `?v=20220724`，封面及正文交给独立随包处理器，按原站客户端的 AES-128-CBC 固定 IV 和 NoPadding 还原。其余图片按普通 URL 读取。 |
| 站点和图源设置 | 保留上游五个预置镜像，自定义 HTTPS 站点覆盖镜像。预置镜像用 `homepageChoices` 同步普通官网入口。任意自定义域名无法经现有静态主页声明同步，作品外链仍按当前站点生成。图源选择提供三个独立官网章节快照共同确认的随机与图源 1–3，作用于章节及更新页的 `?img_host=`。现有宿主只接收成功目录的设置候选，未来若站点新增图源，需要更新源包或扩展宿主协议。 |
| 镜像地址发现 | 站点请求失败时在已知错误响应范围内解析原上游地址页的 `lks`，发现的同站候选随源错误消息返回。宿主不持久化失败响应中的镜像，当前 App 的通用错误 UI 也不展示该消息；源不会静默切换或改写用户选择。 |
| 正式登录 | 固定上游阅读公开目录，无账号取用、登录、授权 Cookie、注册和付费阅读协议。站点自己的账号入口通过普通官网使用。 |

从 0.1.0 候选包提取 WASM，成功回放官网存档排行、分类、关键词搜索、更新、98 章目录及 27 页章页表。随包处理器把 [官网章节存档](https://web.archive.org/web/20240422093925id_/https://manwa.me/chapter/1000941) 首图的官网 CDN 与存档密文均解码为 720×1142 WebP。当前直连旧主域失败，部分预置镜像停用或跳转。237 的 Koma 1.5.5 真机已验证与漫蛙漫画共存。默认入口浏览报无法连接，离线下载待有真实可读入口时验证。包依赖 Koma 1.5.5 的随包图片还原。

对照 [Venera 的同站实现](https://github.com/YHQY-Dev/venera-sources/blob/main/manwa.js) 实读其地址页。地址页公布的四个新域同日三处返回 HTTP 404，一处拒绝连接。候选仍保留原上游身份与镜像配置。
