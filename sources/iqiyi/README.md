# 爱奇艺叭嗒

## 0.1.6 簡介與多語言顯示

愛奇藝叭嗒的漫畫頻道，包含戀愛、奇幻、懸疑與冒險等題材。付費章節仍需原站授權。

零參 `source_info` 固定使用以上基準簡介；`metadata.localization` 僅新增 `source.description` 的繁中、簡中與英文文案，供支援的宿主顯示。

源 ID `com.iqiyi.koma`，当前版本 0.1.4 要求 Koma 0.1.4 或更新版本。支持章节阅读序能力的宿主使用站点 episodeOrder 组织续读；同组重复顺序由宿主处理，目录显示和章节身份保持原样。

阅读接口先确认同一章节。只在接口明确拒绝匿名阅读，返回购买状态及有效章节价格，且没有正文时提示付费；其他同章明确拒绝显示为无权访问。目录的 `free` 和阅读响应中单独存在的价格均不能判断权限，已允许读取的章节照常返回正文。
