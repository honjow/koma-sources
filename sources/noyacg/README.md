# NoyAcg 0.1.9

独立源身份为 `com.noyacg.koma`，主页为 `https://noymanga.com`。提供热门/最新导航及现有搜索、详情、目录和页面接口；接口声明不代表匿名内容当前可用。作品、章节、页面 ID、顺序和分页保持原合同，图标保持官网完整角色图。

作品网页入口使用官网 `/manga/{id}` 路由；源 API 请求路径和作品身份保持原合同。

## 验证与登录

源声明 `https://noymanga.com` 网页会话。用户可在源管理的“验证／登录”打开官网并自行登录；登录后的同站列表、搜索、详情、目录和正文请求可复用该站会话，实际是否可用取决于网站及账号状态。会话仅用于声明的同一 HTTPS origin，不与其他站点共享；包内不包含 Cookie 或账号密码，也不新增原生凭据设置。

## 设置与请求合同

搜索词先还原 JSON 字符串转义，再按表单编码发送。

`POPULAR_MANGAS` 为热门漫画显示内容，默认 `day`（日閱讀榜），另有 `week`（周閱讀榜）和 `month`（月閱讀榜），沿固定 Keiyoushi `949dea252eb8e867b7b40834a26e13088764ff55` 的偏好键、选项及默认值。仅 `listingId=popular` 消费此项；显式 `day/week/month` 导航优先，最新和搜索不消费它。无配置及非法值均保原日榜请求。

排行榜仍使用 `POST https://noymanga.com/api/readLeaderboard`，表单字段为 `type/page`。`ADULT` 按参考提供全年龄、成人或全部三项，默认 `both`；搜索、榜单、详情、目录和页表的 API 请求及图片请求均携带所选 `allow-adult`。原 b1 端点、作品/章节 ID 和本地数据保持；GET 新增默认 `both` 头，图片请求能力启用以传递该头。账户凭据不属于普通设置。受控 WASM 已核请求字段，站点筛选结果及旧章节续读尚未核验。

## 可用性边界

此前匿名排行请求返回 `auth_required`；源仅在精确 `status=login` 标记出现时报告该错误。登录后列表及旧 b1 详情、目录、正文是否可用尚未验证。排行榜偏好请求选择的正确性与内容可用性分别核验。
