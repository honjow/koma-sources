# NamiComi — Traditional Chinese independent Koma source 0.1.3

Stable ID `com.namicomi.zh-hant.koma`; current runtime/crate/package version is 0.1.3. This independent zh-hant source retains its language, IDs, published original first-cover choice, title fallback and complete language-matching catalogue order. Metadata/body/output capacity, strict UTF8/JSON, pagination/identity and API/CDN URL guards remain in force. Source implementation attribution and license remain in NOTICE/LICENSE.

The fixed Keiyoushi 949dea252eb8e867b7b40834a26e13088764ff55 quality contract is exposed through the original dynamic settings controls. `thumbnailQuality_zh-hant` selects original (default `original`, encoding the upstream empty suffix because Host option IDs cannot be blank), medium `.512.jpg`, or low `.256.jpg`; list/search/detail cover URLs append only the selected published suffix. `dataSaver_zh-hant` defaults false; only explicit true chooses the real `low` array and `/low/` image paths from the same chapter response. Otherwise source-quality pages and default URLs are unchanged. Legitimate null name/volume/chapter fields emit an empty source title for the Host's existing localized unnamed-chapter label; no chapter number is fabricated and the valid catalogue is not rejected. No quality URL filename is guessed; IDs, indexes and original array order remain.

Directory visibility defaults to anonymously accessible chapters. On Hosts declaring `source_chapter_exclusions_v1`, the fixed-reference `showLockedChapters_zh-hant` toggle defaults false; explicit true includes validated locked chapter metadata with the reference lock-prefixed title, in original provider order. The source validates the complete catalogue and gating map before visibility filtering; false returns actual owned gating=false IDs in `excludedChapterIds`, so retained Library chapters are hidden from this directory without deleting Library, downloads or reading state. Exact chapter restoration returns only the validated requested identity. Old Hosts retain the original schema and free-only directory, even with a saved new value.

Every page request still performs the original fresh access check before any image request. HTTP401/402, map=false or missing/invalid access records fail without account or token fallback. Showing a locked directory entry grants no page access and adds no credentials, Cookie or login handling. Quality settings retain their original scope.

Build with `bash build.sh --source namicomi-zh-hant`. A build or controlled WASM replay does not imply a named ordinary Native path has been observed.
