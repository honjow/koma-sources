# 瓜子漫画（Guazimanhua）

## 书源简介

瓜子漫画的热门榜以国漫长篇为主，能找到《从姑获鸟开始》《原来，她们才是主角》等作品。书库还按男频、女频分区。

- Source ID：`com.guazimanhua.koma`；版本：`0.1.9`。
- 使用公开页面提供列表、搜索、漫画详情、章节目录和阅读图片；原有分页和筛选合同不变。
- 仅当详情页面的作品标识与请求一致、唯一章节容器存在且没有子元素、移动章节容器不存在，且唯一的更新信息明确显示“最新章节：暂无章节”和“章节总数：0 话”时，目录返回 `no_chapters`。这表示站点当前未提供章节，不推断作品下架。
- 缺失容器、信息冲突或未知结构仍返回解析错误；HTTP 拒绝、限流与 404 沿用各自原有错误分类。

- Mihon 上游的 `Guazimanhua.updateFetchManga` 按站点 DOM 读取同一目录。Koma 的 `get_chapters` 保留该数组方向，用原站阅读页的实际前后章确认它按最新到最早返回。阅读位置按这个目录从旧至新计算，独立于标题和话号。无号正文（如「新767」）、重号和公告保留原站导航位置，原章 ID 与标题继续原样传递。长目录按最后已返回的站点章节 ID 分页，阅读位置跨页保持一致。宿主在完整目录到齐后使用这组顺序。
