# NamiComi — 简体中文独立 Koma 源 0.1.4

稳定 ID `com.namicomi.zh-hans.koma`；当前运行时/crate/包版本为 0.1.4。这个独立 zh-hans 源保留其语言、ID、发布的原第一封面选择、标题回退和完整语言匹配目录顺序。元数据/正文/输出容量、严格 UTF8/JSON、分页/身份和 API/CDN URL 守卫保持生效。源实现归因和许可保留在 NOTICE/LICENSE。

固定 Keiyoushi 949dea252eb8e867b7b40834a26e13088764ff55 质量合同通过原动态设置控件暴露。`thumbnailQuality_zh-hans` 选择原图（默认 `original`，编码上游空后缀因为宿主选项 ID 不能为空）、中 `.512.jpg` 或低 `.256.jpg`；列表/搜索/详情封面 URL 只追加所选发布后缀。`dataSaver_zh-hans` 默认 false；只有显式 true 从同一章节响应选择真实 `low` 数组和 `/low/` 图像路径。否则源质量页和默认 URL 不变。合法 null 名/卷/章字段发出空源标题供宿主既有本地化无名章节标签；不虚构章节编号且不拒绝有效目录。不猜质量 URL 文件名；ID、索引和原数组顺序保持。

目录可见性默认匿名可访问章节。在声明 `source_chapter_exclusions_v1` 的宿主上，固定参考 `showLockedChapters_zh-hans` 开关默认 false；显式 true 包含已验证锁定章节元数据带参考锁前缀标题，按原提供者顺序。源在可见性过滤前验证完整目录和门控映射；false 在 `excludedChapterIds` 返回实际拥有的门控=false ID，故保留的书架章节从此目录隐藏而不删除书架、下载或阅读状态。精确章节恢复只返回已验证的请求身份。旧宿主保留原 schema 和仅免费目录，即使有保存的新值。

每页请求仍执行原新鲜访问检查在任何图像请求前。HTTP401/402、map=false 或缺失/无效访问记录失败无账号或 token 回退。显示锁定目录项不授予页访问且不加凭据、Cookie 或登录处理。质量设置保留其原作用域。

筛选保留既有热门/最新排序和语言作用域；搜索保留其既有可访问章节默认。显式选择应用可用性、内容分级、发布状态和排序。在宿主动态筛选和三态支援下，四个参考标签组在打开筛选时从官方 API 获取；每个标签被忽略、包含或排除，带参考 and/or 模式。标签获取失败仍是错误而非空标签列表。既有章节 ID 和权限检查不变。

用 `bash build.sh --source namicomi-zh-hans` 构建。构建或受控 WASM 回放不意味着具名普通 Native 路径已被观察。
