# MissKon 图标来源

- 原件是[官网首页](https://misskon.com/)用作快捷图标的 [favicon.ico](https://misskon.com/media/2023/12/favicon.ico)，ICO，选取 64×64 像素帧，HTTP 200。视觉对照还包括[官网页头标识](https://misskon.com/img/logo.2026.v5.png)，PNG 210×90。
- ICO 原件带圆角透明蒙版和浅红描边。用原有的红色 RGB(191, 54, 12) 填满四角并去掉描边，保留白色 MissKON 字形、抗锯齿边缘和原比例，再用 Lanczos 放大到 192×192 PNG。
- 已在浅色、深色背景比对官网原件、处理稿、包内图标，核对字形、实角和留白。包内 PNG 与处理稿逐字节一致，Pillow 解码通过。App 书源列表实机呈现依本批范围留待验收。
