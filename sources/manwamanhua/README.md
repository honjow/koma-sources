# 漫蛙漫画

目录和搜索沿用上游的分类与搜索接口及其分页。分类标签在打开筛选时读取。详情、章节、相关作品及分页页图沿用官网接口。当前域名 manwacn.cc 来自官网地址页 mwmw.cc，已验证其 check 接口。上游自动选择域名的逻辑暂待接入。保留官网作品数字 ID、章节路径、频道、台版去重及缺图占位过滤。

图片路径以 /en_images/ 开头时，封面和阅读页交给随包字节处理器。作品评论读取官网 /api/comments 的默认时间顺序。

237 调试宿主已从常规浏览入口显示《一拳超人原作版》首章首图。官网同话页表证实首图走加密路径，页面显示 1/17。作品评论面板显示了官网返回的评论。源包要求 Koma 1.5.5 或以上，以使用随包图片还原。
