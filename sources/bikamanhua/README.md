# 哔咔漫画（同名站）

## 0.1.2 簡介與多語言顯示

bikamanhua.com 的漫畫書庫，按題材、人氣與更新整理作品。這是同名網頁站，與 Picacomic 帳號服務不同。

零參 `source_info` 固定使用以上基準簡介；`metadata.localization` 僅新增 `source.description` 的繁中、簡中與英文文案，供支援的宿主顯示。

独立源 `com.bikamanhua.koma`，对接 `m.bikamanhua.com`。采用上游独立 Mihon ID `8976260719331701966`。官网部分作品封面和正文沿用包子漫画的图片域，作品和章节按本站真实地址保存。

| 行为 | 上游与 Koma |
| --- | --- |
| 热门、最近更新、分类 | 继承 MCCMS 的 `/api/data/comic`、XHR 请求和每页 30 条，热门、更新、评分及官网题材过滤。站内限制不提供连载状态筛选。 |
| 文字搜索 | 首屏 `/search?key=`，后续 `/search/{关键字}/{页号}`，由原下一页链接判断。搜索间隔 1500 毫秒。站点对桌面请求返回空列表，原生搜索使用上游 Android 请求对应的移动浏览器 UA；本机对照确认同一网址只有带移动 UA 才返回作品。 |
| 作品和章节 | 从本作品页解析 `.book-hero`、`.episode-list`，如实按章 ID 用 API 关联日期，目录反转为新到旧。 |
| 正文 | 继承 MCCMS 桌面阅读页的 `img[data-original]`；按上游桌面图像请求设置 User-Agent，图片无需 Referer。 |
| URL 搜索 | 站内作品链接直接打开，章节链接使用原阅读页的返回作品链接。 |

无账号与自定义设置。按用户确认使用「同名站」显示名。
