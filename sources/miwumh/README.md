# 迷雾漫画

迷雾漫画以中文翻译的韩国条漫为主，另有 BL、GL、全年龄和英文栏目。登录后可浏览作品，部分作品单列后记与番外。

- 站点为 https://miwumh.com/。独立源 ID 为 com.miwumh.koma。作品使用 /manhwa/{id}/ 的数字 ID，章节使用同一作品下的 c-{id}。尚无经验证的旧巴卡/Mihon 身份映射。
- 官网网页接收用户名或邮箱、密码及站点验证。Koma 通过官网用户设置管理账号。游客由网站跳到带登录表单的首页。账号材料仍由原站网页处理。
- 首页更新、站点新作、语言与连载状态栏目使用原站页面。搜索发出 s 和 post_type=wp-manga，从搜索专用卡片解析封面和作品。日、周、月榜以排行榜入口读取。本源列表展示原站实际最新话。
- 作品资料页保留别名、作者、标签、简介和原站阅读入口。章节依原站完整列表的最新到最早顺序，保留番外、后记及标题与 URL 编号不同的记录。章名取原站文字链接。阅读按原站图片节点顺序，保留原网址参数和章节 Referer。同站封面与同站正文交由现有图片接口复用本源网页会话。t1.bakamh.de 有独立网页验证。支持 Web HTTP 的宿主先核对本章第一张 CDN 图片，以实际被拒的图址唤起已有阅读验证，再使用图域自己的 Web 会话取得正文。旧宿主沿用普通图片请求。图域不使用主站登录凭据，限制每秒两个请求。
- 作品和章节支持读取原站评论。评论面板单独加载正文与回复，沿用站点顺序及网页会话。
- 最低 Koma 1.6.1。通过原站网页登录及现有网页会话能力加载列表和正文。0.1.6 已在 201 抽查登录后浏览、封面、搜索与 17 部作品的实际阅读。
