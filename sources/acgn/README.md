# 動漫戲說（ACGN）

参考 Keiyoushi 固定版本 `b23481f77aeb7fc0957f15566fb9de647e4b3d3d` 的 `src/zh/acgn`。官网 https://comic.acgn.cc。图标来源见 [ASSET_SOURCES.md](ASSET_SOURCES.md)。

| 功能 | 上游及本源行为 |
| --- | --- |
| 最新漫畫 | Keiyoushi 将首页 `.tabs-panel` 用作其热门入口。Koma 的 `get_listings` 按官网栏目原名展示，`get_manga_list` 合并官网三个最新漫画标签，无下一页。 |
| 分类 | `get_listings` 从官网导航读取并去重分类，供 Koma 浏览下拉直接选择。`get_manga_list` 请求选中分类的分页地址，按官网下一页标记返回数字游标。 |
| 筛选 | `get_filters` 提供官网分类和字母。空关键词的 `search` 共用分类或字母列表的分页处理，分类优先。关键词搜索沿用官网搜索并忽略筛选。 |
| 搜索 | 关键词走官网采用的 Google CSE，跳过只有章节链接的搜索结果页；作品及章节网址可定位所属作品。`search` 以返回游标保存下一页位置。 |
| 详情和目录 | `get_manga` 读取作者、状态、类型、分类、标签、简介、封面及可选关联作品；`get_chapters` 按章节数字 ID 降序，仅给官网标注的最新章节记录台北时区日期。 |
| 阅读 | `get_pages` 使用官网章节页 `#pic_list .pic[_src]` 提供的图片地址，并核对章节所属作品。图片由宿主加载，未改写站点地址。 |
| 登录和设置 | 上游无对应选项，本源也不提供。 |

上游对官网每秒限制两次请求，封面 `/logo/` 除外；当前宿主按域限流声明无法排除该路径，本源保守地将同域封面也计入限流。缺少限流能力时联网请求拒绝执行。

2026-11-12 官网图片节点曾返回 HTTP 522，站点 WebView 同样显示图片缺失。2026-11-15 同一首话首图恢复并返回 JPEG。阅读沿用该章节页指定的图片地址。
