# 布丁漫画

参考 [Keiyoushi 布丁漫画](https://github.com/keiyoushi/extensions-source/tree/f1d882a93ef34a33dc4f4467753ad5f99eab43f4/src/zh/budingmanhua)。原站同时提供不同的桌面和移动 HTML，源的列表、详情和页表均明确请求已核对的移动模板。

- 布丁的默认栏目按上游使用可读的分类书单，避开旧榜单。按主题、地区和进度筛选。站点备用域名顺序与上游一致。
- 关键词走独立搜索入口，保持其单页行为，作品链接保留原作品 ID。
- 目录按原站倒序，用户可继续阅读和切章。章节有多页时依次读取下一页并合并图片。

- 作品评论由作品页提供，打开面板时读取。站点没有提供评论翻页和章节评论入口。
