# 漫小肆韓漫

## 0.1.2 簡介與多語言顯示

漫小肆韓漫的漫畫書庫，地區分類包含韓國、日本與台灣，作品依題材及連載進度整理。

零參 `source_info` 固定使用以上基準簡介；`metadata.localization` 僅新增 `source.description` 的繁中、簡中與英文文案，供支援的宿主顯示。

独立源 `com.ikanmh.koma`。按用户决定沿用 Keiyoushi 的独立移动端扩展和 Mihon 源 ID `8826152585666516354`。站点身份参考 [原移植](https://github.com/keiyoushi/extensions-source/pull/20221) 与 [镜像验证](https://github.com/keiyoushi/extensions-source/pull/20903)。

上游固定于 8947c372cd87f546a0b80cb0e4b0a5a8add5ef88。本机对照了实际热门、最新、搜索和详情的两种响应。站点按文档 User-Agent 切换模板，三个已声明域名共用上游移动版解析，原生文档请求明确使用移动浏览器 UA。素材取自官网原件。

## 0.1.3 原站作品评论

宿主声明 `source_comments_v1` 后，`get_comments` 使用所选镜像的作品详情页，读取原站显示的只读评论，保留站方顺序；移动及桌面模板分别解析，作品 ID 与页面内 `book_id` 一致才接受。站方没有提供可用评论 ID，点赞控件的 ID 会重复，因此使用作者、日期和正文生成列表身份，并区分完全相同的重复行。

2026-11-24 实际页面的评论列表直接嵌在 HTML 中；移动页的 `999+` 是固定标签，桌面页分页栏为空且隐藏，`comment.js` 仅提交评论，`index.js` 未提供评论续页。当前不返回续页游标，也不声明章节评论。网站未来增加分页时须重新核对请求与停止条件，不能根据标签推测。

本機驗證：0.1.3 WASM 實際讀取預設站 `/book/1262`、`/book/1007`、`/book/1054`、`/book/1103`，分別取得 1、1、5、0 條；1262 在另外兩個已設定鏡像均取得同一條。拒絕章節作用域、續頁游標及未協商能力。桌面模板已核對原站 HTML，WASM 桌面分支與 App 真機入口尚未驗證。
