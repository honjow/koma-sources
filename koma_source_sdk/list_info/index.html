Optional ordered list-item metadata. Call inside an existing item’s object. Unsupported hosts keep byte-identical legacy fields. Validation/capacity errors leave both the cursor and buffer untouched; callers may omit this enhancement.

append
Append ,"listInfo":[...] before the existing item object’s closing brace. Ok(false) means no negotiated feature. Empty entries explicitly write [] to disable legacy field summaries; omitting this call preserves fallback. Empty/whitespace-only fields, invalid UTF-8 and byte/count limits reject the whole optional field. Text512/label96, tags1..=8/tag96, entries1..=3 are UTF-8 byte limits, not chars. This does not fetch, infer labels/locales, parse HTML or alter existing fields. On Err, omit the optional enhancement rather than dropping an otherwise valid item.
